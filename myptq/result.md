# FEMBA-Tiny 实验结果、受试者划分测试与 INT4 固定方案

本报告基于当前 `result/` 归档重写，覆盖 TUAR 原始划分、yuantong 提供的 TUAR 受试者划分，以及 TUSL-events-v2 三分类四折。数据划分名称按交付目录和本组说明标注。归档中的训练、预测文件和元数据用于核对模型与指标；受试者是否完全互斥仍需原始受试者名单或数据构建清单验证。

受试者划分下，TUAR 的 W4A32 是当前能保留大部分性能的 INT4 权重方案。按既定验证规则，固定 FP32 父模型、部分 Hadamard 旋转块 64、分组 64、MSE。测试 AUROC 为 0.862881，比对应浮点下降 1.855 个百分点。BF16 的 W4A32 候选测试 AUROC 更高，为 0.881921，但其验证 AUROC略低，因此列为独立对照。TUSL 固定四折共同的 W4A32、全 Hadamard 旋转、不分组，平均测试 AUROC 为 0.851174，下降 0.368 个百分点。两个数据集的 W4A8 均存在明显分类能力损失，W4A4 也未保持有效性能。

## 2. 实现与选择规则

- 两个数据集的输入均为 22 通道、1280 点。TUAR 为二分类，TUSL 为三分类，归一化沿用父 checkpoint 的设置。
- HF 权重加载的是预训练骨干，分类头在对应任务中训练。随机初始化运行明确未加载预训练 checkpoint。FP32 和 BF16 指微调精度，后续 PTQ 统一用 FP32 fake quant。
- 扫描固定 `all-weights`、MSE、Hadamard、旋转 seed 2025，部分旋转块为 64。分组为 32、64、128、none。`none + channel` 表示每输出通道一个尺度。
- A8/A4 使用 sequential 校准，百分位 99.999、窗口上限 1024、batch 32、seed 42、quantized 权重状态。TUAR 使用抽样窗口，TUSL 使用各折全部训练窗口。test 使用保存的有效权重和冻结尺度。
- 权重旋转后量化，再逆旋转缓存有效浮点权重，激活仍在原坐标量化。卷积使用对称量化，bias、LayerNorm、位置参数、A_log/D 等保持浮点。
- 每个 W/A 在验证集按 AUROC、AP、较低 Loss 排名。TUAR 每份父模型各选候选，W4A32 与 W4A8 再分别跨父模型选主方案。TUSL 先对四折同一配置取等权平均验证指标，再选共同配方。
- TUAR PTQ 使用 `z1-z0` 计算 AUROC，日志使用正类 logit。初始化对照表尽量统一使用日志口径，量化下降则使用同一入口下的浮点基准。TUSL 使用宏平均 one-vs-rest AUROC、宏 F1、宏召回率。TUSL 总结果按四折等权平均，按窗口评估。
- 下面的“最佳”指已扫描范围内按验证规则选出的方案。测试成绩用于报告，未用于回改配置。

### 5.2 W4A8、W4A4 当前无法保持分类能力

FP32 W4A8 与两份 W4A4 都将 7709 个测试窗口全部预测为正类。BF16 W4A8 只预测 30 个窗口为负类，其中 19 个仍是实际正类，平衡准确率为 0.499036。其测试 AUROC 为 0.570536，F1 为 0.673559。这与有效识别正负类有明显距离。W4A4 的 AUROC 可以高于部分 A8 配置，但仍有单类预测，不能据此判断 A4 更可用。

W8A8 同样大幅退化，说明问题首先集中在激活量化及其与权重量化的交互。现有结果不能把失效完全归因于某个算子。训练集校准范围与受试者验证、测试分布之间的偏移、量化点位置和累计误差都需要配对排查。

### 5.3 “验证选定”与“测试最高”需要分别报告

已归档 `fixed_INT4.json` 按验证规则选定 FP32 的 W4A32，验证 AUROC 为 0.917748，略高于 BF16 候选的 0.916451。测试上 BF16 候选更好，0.881921 高于 FP32 的 0.862881。本文保留原验证规则选定产物作为正式固定方案，把 BF16 标为测试表现更好的备选。若课程决定统一固定 BF16 父模型，应将其写成预先约束或新的验证协议，不能把测试排名当成验证选择结果。

W4A8 在两份父模型间按验证选择了 BF16 对称不分组，验证 AUROC 仅 0.479617。它是已扫描 W4A8 候选中的最大值，仍应记为该激活量化路径失效的对照。

## 10. 固定文件复评及结论边界

取回原远程量化 checkpoint 后，核对本节给出的完整 SHA256。复评使用冻结文件，父模型微调精度由元数据记录，推理统一使用 FP32。运行示例如下。

```bash
DATA=/workspace/EEGdata/tuar
FIXED=/workspace/results/TUAR_rerun/fp32/ptq/sweep/w4a32_block_mse_73755ebc46/myptq.ckpt
sha256sum "$FIXED"
python -u myptq/code/ptq.py \
  --checkpoint "$FIXED" --load-calibrated \
  --data-dir "$DATA" --split test --batch-size 32 \
  --output-dir /workspace/results/fixed_TUAR_W4A32_retest
```

TUSL 将 checkpoint 换为对应折的第 9.4 节路径，数据换为 `/workspace/EEGdata/tusl-events-20261026-v2/foldN`，各折输出到独立新目录。文件缺失时需从对应父 checkpoint 重建，A8/A4 尤其要保留原校准数据、索引、尺度和实现版本。

使用 yuantong 数据的 INT4 结论分两层。W4A32 在 TUAR 和 TUSL 都有可复现的精度保持候选，TUAR 的阈值误报变化需要单独报告，TUSL 的平均损失更小。W4A8 在 TUAR 接近单类预测，在 TUSL 则保留排序但明显损伤宏 F1，当前均不能宣称保持浮点分类精度。W4A4 在两个数据集都严重退化。

当前为单 seed 的窗口级 fake-quant 实验。数据受试者互斥性应由名单和构建清单核对，事件级指标、真正的整数部署速度与压缩体积还需独立测量。上述固定路径是归档记录的原远程位置，本地还需补齐权重文件。
