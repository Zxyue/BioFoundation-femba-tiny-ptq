# TUSL 四折实验执行结果

## 数据与统计口径

本报告合并 `result/seed42`、`result/seed43`、`result/seed44` 和 `result/W32A32-seed424344` 的 `summary.json`，覆盖六种配置、四折、三个种子（42、43、44），共 72 条正式流程。W32A32 的权重与激活量化开关均为 0，是浮点对照。其余五组在指定位置使用 fake quant。

两批记录均使用 `tusl-events-20261026-v2` 数据集，预训练 50 轮，微调 10 轮。每条流程随机初始化预训练，微调从 `final.ckpt` 开始，按验证集最低 `val_loss` 选 checkpoint 后评估测试集。表中的指标按事件计算，每个事件的两个窗口取 softmax 概率平均。每次运行共覆盖 24 名测试受试者、153 个事件、306 个窗口。三个种子重复使用这些划分。

每个种子先等权平均四折，再对三个种子的折均值计算均值和样本标准差。表中的 ± 表示种子间波动。Macro F1 衡量三类预测的精确率和召回率，balanced accuracy 是三类召回率的均值，AUROC 和 AP 衡量按预测分数排序的效果。

## 结果解释

- **W4A8 与 W8A8 的均值最接近。** 两组 Macro F1 分别为 66.91% 和 66.42%，差约 0.50 个百分点，三种子的排名互有领先。W4A8 在三个种子上均高于 W32A32，平均 F1 高 17.36 个百分点。
- **W4A4 对种子更敏感。** seed42 的 F1 为 67.71%，seed43 和 seed44 分别为 54.24% 和 53.75%。W4A4 使用 95% 初始校准分位数，W4A8 使用 99.9%，两组同时改变了位宽和校准参数。
- **关闭激活量化的权重量化组分数较低。** W4A32 的 F1 比浮点低 4.27 个百分点。W8A32 的平均 F1 与浮点接近。各组独立完成预训练和微调，分数差异反映整条流程。
- **AUROC 和最终分类表现有差距。** W32A32 在 seed42/fold0 的 AUROC 为 86.91%，Macro F1 为 36.84%，Accuracy 为 38.18%。原五组里，W4A8 的同一折也出现背景误判，seed42 有 29 个背景事件，仅识别正确 1 个。综合比较时应同时查看 Macro F1、balanced accuracy 和混淆矩阵。

## 可比性与结论边界

`campaign.json` 显示两批核心源码哈希和训练预算一致，工具脚本哈希和依赖环境存在差异。浮点组在 `/workspace` 环境执行，原五组来自集群环境，PyTorch 构建、Lightning 和 NumPy 版本有差别。两批记录的数据集名和汇总样本数相同，支持将 W4A8 作为四位权重候选，与 W8A8 表现接近。
